# **App Name**: ExamPrep

## Core Features:

- User Authentication: Secure Google sign-in/login using Firebase Authentication.
- Practice Setup: Clear flow for users to select exam (JEE/NEET), subject, topic, and difficulty level.
- Focused Practice Interface: Minimalist exam interface with controls: Save & Next, Mark for Review, Clear Response, and a question palette for easy navigation.
- Results & Analysis: Immediate performance summary and detailed, question-by-question review with time taken, correct answer, and solutions.
- User Profile: Personal dashboard for viewing the history of completed practice sessions.
- Feedback Mechanism: Simple form for users to submit feedback, report issues, and request new features.
- AI Question Generation: Utilize an AI tool to generate practice questions of varying difficulty levels based on the user's selected topic and exam. 

## Style Guidelines:

- Primary color: Light teal (#A7DBD8) for a calming and focused environment, drawing inspiration from the minimalist design principles.
- Background color: Pale grey (#F0F4F3), creating a distraction-free backdrop.
- Accent color: Soft orange (#E08E79) to highlight key interactive elements like buttons and important information, while providing enough color contrast.
- Body: 'PT Sans' a sans-serif for readability. Headlines: 'Playfair', a modern sans-serif with an elegant feel for the titles.
- Use minimalist icons for subjects and controls for intuitive navigation.
- Prioritize a clean layout with generous white space for clarity and focus. The practice screen should be free of non-essential elements.
- Subtle animations when transitioning between questions and displaying results to provide feedback.
